# Privacy policy: Personal Expense Tracker

This is a personal, self-hosted tool used only by its owner. It is not offered to the public.

- It reads bank alert emails from one Gmail label using read-only access (gmail.readonly).
- It stores only transaction details (amount, date, merchant, last 4 digits of an account)
  in a database on the owner's own computer or server.
- It never stores full email bodies, full account numbers, or bank balances.
- It never sends Gmail data to any third party, and it cannot send, change, or delete email.
- Access can be revoked at any time at https://myaccount.google.com/permissions.
